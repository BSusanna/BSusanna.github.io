# Susanna Bardini

Academic website for [Susanna Bardini](https://bsusanna.github.io/), PhD student in Information Technology at Politecnico di Milano.

## Public sections

- [Home](https://bsusanna.github.io/)
- [Publications](https://bsusanna.github.io/publications/)
- [CV](https://bsusanna.github.io/cv/)

## Local development

```bash
bundle install
npm ci
bundle exec jekyll serve
```

The site is deployed by `.github/workflows/deploy.yml` to the `gh-pages` branch.
